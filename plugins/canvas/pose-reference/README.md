# 姿势参考节点

节点默认使用「白膜工作台」：连接一张人物原图，选择 3D 白膜预设姿势，在白膜上拖动调整机位，选择全身、半身或近景，再点击「生成这个姿势」。生成时会将当前白膜视角渲染成参考图；人物原图负责身份、服装和场景，白膜图只负责姿势、机位和景别。

「图片参考」模式保留原来的两图参考方式，可分别指定人物原图和姿势参考图。两种模式都会在节点右侧新增连线结果，重复生成依次向下排列，并使用画布当前的生图模型与配置。

白膜不携带其他人物的服装和道具，但模型仍可能把没有支撑物的坐姿理解成跪坐等相近姿势；它是可旋转的视觉参考，不是逐关节精确约束。盘腿坐姿提供无家具的坐姿参考。

本地开发运行 `npm run build` 后，插件会同步到 `web/public/plugins/pose-reference.js`，可在节点管理器中启用。
