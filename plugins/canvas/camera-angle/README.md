# 换角度节点

连接一张图片到「换角度」节点。可以直接拖动球内的参考图平面调整机位，也可以用左右、上下两个滑杆精调；两种操作会同步。球面网格、相机位置标记和方向文字会随角度变化。左右机位为完整一圈（-180° 到 180°，0° 正面、±90° 侧面、±180° 背面），上下机位从正下方 -90° 到正上方 90°。超过水平 180° 时会从另一侧继续旋转。球体与平面只表示拍摄方向，不会改变原图；转到背面时显示空白背面示意，未知细节由模型生成。点击「生成这个角度」后，节点使用画布当前的生图模型和原图作为参考，在右侧新增图片并建立连线；同一节点再次生成的结果会依次排在已有结果下方。角度与细节保持程度取决于所选模型，生成失败时保留原图和当前角度并显示错误。

本地开发运行 `npm run build` 后，插件会同步到 `web/public/plugins/camera-angle.js`，可在节点管理器中启用。
