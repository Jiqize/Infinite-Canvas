# 分镜脚本节点(storyboard)

剧本 → 可编辑分镜表 → 勾选行批量出图、批量出视频。

- 剧本:节点内输入;留空时取上游文本节点内容。「拆分镜」调用文本模型输出分镜 JSON(镜号 / 时长 / 景别 / 画面描述 / 角色主体)。
- 分镜表:各列可编辑,可增删行,镜号按行序自动重排;行数据存 `metadata.rows`。
- 批量出图:勾选行逐条生成(并发 3),参考上游图片,在节点右侧铺成图片节点「镜 N」。
- 批量出视频:只对勾选且已出图的行可用,以分镜图为首帧、行时长为视频时长,在图片节点右侧生成「镜 N 视频」并连线。

纯逻辑在 `src/logic.ts`,测试 `bun test`。官方构建走 `plugins/canvas/registry`(`npm run build`)。
